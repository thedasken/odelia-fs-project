# Repository workflow

- Do all project work on the local `main` branch.
- `main` must track `fork/main`, where `fork` is `https://github.com/thedasken/odelia-fs-project.git`.
- Commit and push project changes to `fork`'s `main` branch so they are available in the user's fork.
- Treat `origin` (`https://github.com/bgoetzmann/odelia-fs-project.git`) as the upstream source repository; do not push to `origin`.
- Before making changes, confirm the current branch is `main`. If it is not, switch to `main` before editing.
